# Industry Scenarios (Legacy Runtime)

`run_scenarios.py` contains eight runnable demonstrations for the retained v1
`GovernancePipeline`, including procurement, pricing, velocity, orchestration,
IT operations, replay, delegation, and fleet budgets.

```bash
python -m glassbox.scenarios.run_scenarios
```

The scenarios are educational. Their policy identifiers, outcomes, and
framework references are not production configurations, certifications, or
evidence that a deployment satisfies an industry obligation.

For current architecture patterns, see
[enterprise use cases](../../docs/USER/use_cases.md).
